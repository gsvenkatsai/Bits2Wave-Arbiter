HOW ARBITER WORKS.

PROJECT ARBITER acts as an in-line conflict-resolution referee embedded within the O-RAN Near-RT RIC. Every 100 ms tick, candidate proposals from independent autonomous controllers are captured, checked against physical and interference dependencies, simulated counterfactually in a calibrated digital twin with conformal uncertainty intervals, and synthesized into a Pareto-optimal joint actuation vector before over-the-air deployment.

The 100 ms Tick Feedback Loops

Within the Near-RT RIC 100 ms execution envelope, ARBITER completes four tightly coupled algorithmic feedback loops.

Loop 01

Hold Loop

Manages transient conflicts (e.g., active handovers in flight). Requests are held for up to 3 ticks before forcing bisection morphing or rejection if prerequisite states remain blocked.

Loop 02

Twin Calibration

Maintains a 200-tick rolling calibration buffer of telemetry residual errors, computing split conformal prediction quantiles ($1-\alpha = 0.90$) with a cold-start safety guard ($n < 30$).

Loop 03

Plan Synthesis

Evaluates the combinatorial joint space ($\le 64$ candidates) in 3.82 ms, applying parameter bisection to prune constraint-violating actions into safe, Pareto-optimal setpoints.

Loop 04

Operator Risk Dial

Enforces policy weight vectors across Energy ($\alpha$), Throughput ($\beta$), and Coverage ($\gamma$), allowing live switching between Balanced, Aggressive, and Conservative operating points.

// REFEREE ARBITRATION TAXONOMY

The Decision Ladder

Every controller command is resolved through a deterministic four-tier arbitration ladder.

Tier 01 • Action

APPROVE

Action introduces no direct or indirect conflicts and satisfies all conformal KPI safety bounds. Dispatched as proposed.

Tier 02 • Action

MODIFY (Bisection)

Action exceeds cell capacity or headroom in raw form. ARBITER tunes parameter magnitude (e.g. offload ratio 40% $\rightarrow$ 15%).

Tier 03 • Action

DELAY (Hold Count)

Action conflicts with in-flight transitional states (such as handovers). Held in queue for up to 3 ticks until queues clear.

Tier 04 • Action

REJECT

Action unrecoverably breaches minimum SINR floors or hard safety constraints with no viable intermediate parameter setpoint.

// STANDARDIZED ARBITRATION VERDICT CODES

Auditable Reason Codes Catalog

Every verdict emitted by ARBITER carries an immutable reason code corresponding directly to arbiter.shared.models.ReasonCode.

NONE
Unconditional Approval

No conflict or constraint violation detected. Proposed action is compliant with all active policies and conformal bounds.

ACTIVE_HO
Active Handover In-Flight

Mobile terminals are currently in transition to or from the target sector. Action is delayed to prevent dropping active handovers.

HEADROOM
Capacity / Headroom Exceeded

Target cell PRB utilization, queue length, or RF link budget cannot accommodate the full proposed magnitude; action is modified.

CYCLIC_PINGPONG
Cyclic Ping-Pong Oscillation

Detected an oscillatory hysteresis pattern between opposing controller actions across consecutive ticks; command suppressed.

TWIN_TIMEOUT
Simulation Latency Timeout

Digital twin counterfactual simulation did not complete within the strict 10 ms budget; failsafe conservative action applied.

UNCERTAINTY_GUARD
Conformal Uncertainty Guard

Split conformal interval width exceeds acceptable safety tolerance due to sudden traffic non-stationarity or cold-start conditions.

FLOOR_BREACH
KPI Floor Breach

Predicted radio Key Performance Indicator breaches a mandatory operator safety threshold (such as minimum user SINR floor).

EMERGENCY_OVERRIDE
Emergency Priority Override

Network health supervisor or operator manual policy triggered an administrative override of automated controller proposals.
