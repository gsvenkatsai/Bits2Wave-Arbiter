How to Reproduce

Execute these exact commands in PowerShell to reproduce every benchmark figure locally:

1. Launch Full 3D Simulation & WebSocket Demo:
powershell -ExecutionPolicy Bypass -File scripts\run_demo.ps1
2. Run 64-Combo Optimality Solver CLI:
python -m arbiter.simulator.optimality --seed 42

python -m pytest tests/branch4/test_benchmarks_runner.py -v

Limitations

Honest boundaries of the current implementation:

  • Simulation-Based Prototype: All experiments were evaluated in a software-defined discrete-event RAN simulator implementing COST-231 Hata path loss. Physical hardware over-the-air deployment will exhibit additional non-linearities and multipath fading.
  • Synthetic Traffic Distribution: Active user mobility and traffic arrival rates are modeled via synthetic Poisson processes calibrated against Milan urban cellular mobility statistics.
  • Vendor SMO Benchmarks: Figures referenced for commercial SMO and SON conflict management systems are standard industry benchmarks and do not represent direct measurements on proprietary closed-source vendor equipment.
