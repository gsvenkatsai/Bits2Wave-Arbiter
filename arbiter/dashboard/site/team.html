Technologies & Libraries

Engineered with modern, deterministic, zero-CDN local libraries:

Python 3

Core discrete-event simulator, async telemetry orchestration, and conformal mathematical interval routines.

NumPy

Vectorized radio channel calculations, multi-cell SINR matrices, and fast split-conformal non-conformity scoring.

NetworkX

Conflict graph modeling, bipartite matching algorithms, and Tarjan cycle detection for cyclic ping-pong prevention.

FastAPI & Uvicorn

High-throughput sub-10ms REST ingestion endpoints and bi-directional live WebSocket telemetry streams.

SQLite (WAL Mode)

Deterministic 600-frame unified ring buffer, state checkpoint persistence, and forensic audit logging.

Three.js

GPU-accelerated WebGL digital twin, InstancedMesh user rendering, and dynamic RF radiation lobe geometry.
